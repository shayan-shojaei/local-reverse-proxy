## [0.1.0] - 2026-09-16

### Added

- Dockerized controller, Caddy, and CoreDNS stack.
- Route dashboard and versioned route-management API.
- Local HTTPS through Caddy's persistent internal CA.
- macOS and systemd-resolved Linux bootstrap CLI.
- One-line installer with downloadable CLI release archives.
- Route reachability checks, enable/disable controls, and configuration import/export.
